# استخدامي (Used)

تطبيق Android محلي يعرض استخدام الجهاز والتطبيقات بالتفصيل.

## المزايا
- اليوم، أمس، هذا الأسبوع، والأسبوع الماضي.
- إجمالي مدة استخدام كل تطبيق وترتيب الأكثر استخدامًا.
- عدد الجلسات، أول وآخر استخدام، أطول جلسة، ومتوسط الجلسة.
- صفحة مستقلة لكل تطبيق تعرض كل جلسة بصيغة **من → إلى**.
- أرشفة محلية للإجماليات اليومية والجلسات المتاحة من Android.
- Android Auto Backup بالإضافة إلى تصدير/استيراد نسخة JSON يدويًا.
- يحتفظ باسم التطبيق وسجله في الأرشيف حتى إذا حُذف ذلك التطبيق لاحقًا.

## الخصوصية
يطلب التطبيق صلاحية **Usage Access** فقط. لا يستخدم Accessibility ولا يقرأ الرسائل أو كلمات المرور أو النصوص داخل التطبيقات، ولا يرسل سجل الاستخدام إلى خادم.

## البيانات السابقة
بعد التثبيت لأول مرة يقرأ التطبيق ما لا يزال Android يحتفظ به من UsageStats، لذلك يمكن أن تظهر بيانات أمس والأسبوع الماضي مباشرة متى كانت متاحة في النظام. تفاصيل الجلسات الدقيقة عمرها أقصر من الإحصاءات المجمعة، لذلك يبدأ التطبيق بأرشفتها محليًا من وقت تثبيته.
