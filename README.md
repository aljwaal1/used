# Used — Android Device Usage Dashboard

تطبيق أندرويد محلي لعرض ملخص استخدام الجهاز مع فترات:
- اليوم
- أمس
- هذا الأسبوع
- الأسبوع الماضي

النسخة الأولى تعتمد على Android UsageStatsManager بعد منح المستخدم صلاحية Usage Access، وتعرض وقت استخدام التطبيقات، ترتيب التطبيقات الأكثر استخدامًا، وعدد أحداث استخدام/فتح الجهاز المتاحة من النظام.

الخصوصية: لا يتم رفع البيانات إلى خادم، ولا يقرأ التطبيق محتوى المحادثات أو كلمات المرور أو النصوص داخل التطبيقات.
